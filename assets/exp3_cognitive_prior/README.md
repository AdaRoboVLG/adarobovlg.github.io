# Experiment 3 shared assets

These images were exported from slides 19–22 of `ppt_video/PPT/TRO26-AdaRoboVLG.pptx` for the Cognitive Prior website evidence viewer.

Each object directory contains:

- `input.png`: task input image;
- `functional-part.png`: predicted functional part highlighted in red;
- `grasp-type.png`: corresponding grasp-type illustration.

The asset paths are shared across timestamped website versions through `/assets/exp3_cognitive_prior/...`.
