# Experiment 2 spatial-prior videos

Shared web assets extracted from slides 15–17 of `TRO26-AdaRoboVLG_no_voice.pptx`.

- `dh3/`: DH3 (3F), 18 scenes
- `allegro/`: Allegro (4F), 18 scenes
- `inspire/`: Inspire (5F), 18 scenes
- Scene IDs run from `scene_0100` through `scene_0185` in increments of five.

These files intentionally live outside `web/version/` so all website snapshots can reference the same videos through `/assets/exp2_spatial_prior/...`.
